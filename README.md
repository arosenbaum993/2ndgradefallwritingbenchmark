# Grade 2 Fall Writing Benchmark

Standalone HTML practice screen for the Grade 2 ELA opinion writing task
(ELAGSE2W1). Two paired sources on classroom pets, a DRC INSIGHT-style
toolbar (highlight, notepad, text size, line reader, checklist, full screen),
and a printable lined response sheet. Students read on screen and write on paper.
Nothing is submitted through the page.

## Use

1. Open `index.html` in Chrome, or serve the repo with GitHub Pages.
2. Press **Start Practice Test** to enter full screen. Sandboxed embeds fall
   back to a pop-out window; allow pop-ups if prompted.
3. Press **Print Paper** to print the lined response sheet.

Notepad text is kept in `sessionStorage` only, so it clears when the tab closes.
